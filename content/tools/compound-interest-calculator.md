# Compound Interest Calculator

Project your future corpus using starting amount, monthly contribution, expected annual return, and time horizon. This calculator helps you understand how consistency and compounding can grow long-term wealth.

## 🚀 Features

- **SIP + Lumpsum Support** — Model one-time amount and monthly additions together
- **Year-by-Year Projection** — See how invested amount vs returns evolve over time
- **Scenario Comparison** — Compare conservative, moderate, and aggressive return assumptions
- **Instant Recalculation** — Results update as inputs change
- **Goal-Focused Planning** — Estimate how much to invest for retirement, education, or house goals
- **Mobile-Friendly UI** — Quick planning from any device

## 📖 How to Use Compound Interest Calculator

1. **Enter Initial Amount** — Optional starting corpus.
2. **Add Monthly Contribution** — Your recurring monthly investment amount.
3. **Set Return Rate** — Expected annual return (test multiple scenarios).
4. **Choose Duration** — Number of years for projection.
5. **Review Results** — Check total invested, estimated returns, and final corpus.
