# World Clock

Track current time across multiple time zones with live updates.

## 🚀 Features

- **100% Client-Side Processing** - Your data never leaves your browser
- **Live Time Updates** - Real-time clock for every timezone
- **Multiple Cities** - Track time in several cities simultaneously
- **Custom Selection** - Add or remove cities from your dashboard
- **DST Aware** - Automatic daylight saving time handling
- **No Sign-Up Required** - Start using immediately
- **Privacy-First** - Zero data collection or storage
- **Completely Free** - No hidden costs or premium tiers

## 📖 How to Use World Clock

1. **Open the Tool**: Navigate to the World Clock on CodelithLabs
2. **View Default Cities**: See popular timezone clocks
3. **Add Cities**: Add custom cities/timezones to track
4. **Monitor**: Watch live time updates across all zones
5. **Compare**: Quickly compare times across different regions
